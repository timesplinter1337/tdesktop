Плагины для Telegram Desktop

Встроенная среда выполнения Lua 5.4 внутри официального клиента Telegram Desktop. Плагины дают доступ к управлению стилями Qt (QSS), перехвату ввода, изменению сообщений перед отправкой, выполнению слэш-команд, асинхронным HTTP-запросам и таймерам.

Быстрый старт

Каждый плагин представляет собой отдельный .lua файл. Чтобы запустить свой первый скрипт, достаточно положить его в каталог plugins рядом с исполняемым файлом Telegram.exe.

plugins/hello_world.lua 
PLUGIN = {
    name = "Привет, мир!",
    description = "Демонстрация базового перехвата сообщений",
    version = "1.0.0",
    author = "timesplinter"
}

function on_enable()
    telegram.ui.show_toast("Плагин успешно включен!")
end

function on_message_send(text)
    if text == ".ping" then
        return "pong! (отправлено через плагин)"
    end
    return text
end
Обратите внимание: если вернуть из on_message_send пустую строку "", отправка сообщения будет заблокирована клиентом.

Структура файлов

В папке клиента все ресурсы плагинов хранятся изолированно от пользовательских баз MTProto:

Дерево каталогов 
Telegram.exe              # Исполняемый файл клиента
lua54.dll                 # Динамическая библиотека среды Lua
plugins/                  # Рабочая директория плагинов
  ├── plugins_config.json # Состояние активности плагинов (включен / выключен)
  ├── custom_theme.lua    # Стилизация и переключение QSS тем
  ├── mega_tools.lua      # Слэш-команды (/calc, /timer, /quote)
  └── shrug_and_greeter.lua # Быстрые автозамены смайлов

Интерфейс настроек

В клиенте интегрирован раздел управления плагинами. Откройте Настройки (Settings) → выберите раздел Plugins.

Каждый найденный скрипт отображается в списке отдельной строкой с кнопкой-тумблером:

  • Переключатель сразу вызывает on_enable() или on_disable() в среде Lua.
  • Выбор сохраняется в plugins_config.json и восстанавливается при следующем перезапуске Telegram.
  • Ошибки выполнения Lua-кода выводятся во всплывающих уведомлениях (Toast) и пишутся в системный log.txt.

Метаданные PLUGIN

Каждый скрипт объявляет глобальную таблицу PLUGIN в начале файла. Эти данные считываются клиентом при парсинге каталога:

Поле Тип Обязательное Описание
name string Да Имя плагина, выводимое в заголовке настроек.
description string Нет Краткое описание назначения скрипта.
version string Нет Версия (например, "1.0.0").
author string Нет Автор или никнейм создателя.

Хуки событий (Hooks)

C++ ядро вызывает соответствующие Lua-функции в ключевые моменты жизненного цикла интерфейса и сети:

Функция Аргументы Возвращаемое значение Когда вызывается
on_enable() — — При включении плагина в настройках или при старте приложения.
on_disable() — — При выключении тумблера плагина пользователем.
on_message_send(text) text (string) string | nil Перед отправкой текста в сеть. Позволяет модифицировать или заблокировать отправку (пустая строка).
on_message_received(peer_id, text) peer_id (int), text (string) — При получении нового входящего сообщения в любом открытом диалоге.
on_command(cmd, args) cmd (string), args (string) boolean При вводе текста, начинающегося со слэша (/calc 2+2). Если вернуть true, отправка в чат подавляется.
on_chat_changed(peer_id) peer_id (int) — При переключении пользователя на другой чат или канал.

telegram.ui

Методы изменения внешнего вида приложения на базе стилей Qt Widgets (QSS), всплывающих подсказок, модальных диалогов и контекстных меню.

telegram.ui.set_style_sheet(qss: string)

Устанавливает глобальный стиль приложения (эквивалент qApp->setStyleSheet). Переопределяет любые цвета, скругления, фон и шрифты всех виджетов.

telegram.ui.add_style_sheet(qss: string)

Дописывает фрагмент QSS к текущему активному стилю приложения без сброса уже примененных правил.

telegram.ui.show_toast(text: string)

Показывает системное всплывающее уведомление Telegram Desktop в нижней части активного окна.

telegram.ui.get_input_text(): string

Возвращает текущий черновик текста, набранный пользователем в строке ввода активного чата.

telegram.ui.set_input_text(text: string)

Подставляет указанный текст в поле ввода текущего чата.

telegram.ui.add_message_action(title: string, callback: function)

Добавляет пользовательский пункт в контекстное меню сообщения (правый клик по сообщению в истории). Функция обратного вызова принимает таблицу с полями сообщения:

  • msg.id (number) — идентификатор сообщения в чате.
  • msg.text (string) — текст сообщения.
  • msg.peer_id (number) — числовой ID чата или пользователя.
  • msg.sender_id (number) — ID автора сообщения.
  • msg.is_outgoing (boolean) — true для исходящих сообщений.
telegram.ui.add_chat_action(title: string, callback: function)

Добавляет действие в контекстное меню диалога (правый клик по чату в левом списке). В callback передается таблица с атрибутами чата:

  • chat.id (number) — числовой ID чата.
  • chat.name (string) — название диалога, канала или имя пользователя.
  • chat.is_user (boolean) — признак личной переписки.
  • chat.is_channel (boolean) — признак канала или супергруппы.
telegram.ui.alert(title: string, text: string)

Отображает нативное модальное окно Telegram Desktop поверх интерфейса с заголовком, текстом и кнопкой «OK».

telegram.ui.confirm(title: string, text: string, callback: function)

Открывает нативное диалоговое окно подтверждения с кнопками «Да» и «Отмена». При клике вызывается callback(confirmed: boolean).

telegram.ui.prompt(title: string, placeholder: string, default_value: string, callback: function)

Открывает нативное окно запроса пользовательского ввода со строковым полем InputField. При нажатии «OK» вызывает callback(input_text: string).

telegram.clipboard

Взаимодействие с системным буфером обмена ОС Windows через QGuiApplication::clipboard().

telegram.clipboard.get(): string

Считывает текущее текстовое содержимое из буфера обмена. Если буфер пуст или содержит нетекстовые данные, возвращает пустую строку.

telegram.clipboard.set(text: string)

Помещает переданную текстовую строку в буфер обмена операционной системы.

telegram.privacy

Управление приватностью и сетевыми статусами на уровне ядра клиента. Позволяет читать сообщения без отправки отчетов о прочтении и печатать текст без отображения статуса «печатает...».

telegram.privacy.set_ghost_mode(enable: boolean)

Включает или выключает полный режим невидимки («Ghost Mode»). Одновременно активирует подавление статуса набора текста и блокировку отправки отметок о прочтении на серверы Telegram.

telegram.privacy.is_ghost_mode(): boolean

Возвращает true, если полный режим невидимки активен.

telegram.privacy.set_typing_blocked(enable: boolean)

Подавляет отправку исходящего статуса набора текста (SendProgressManager::send). Собеседники в любых чатах не видят индикатор набора сообщения.

telegram.privacy.is_typing_blocked(): boolean

Возвращает текущее состояние блокировки статуса набора текста.

telegram.privacy.set_read_blocked(enable: boolean)

Перехватывает и блокирует отправку серверных запросов прочтения (Histories::sendReadRequests). Вы можете открывать любые диалоги и просматривать историю сообщений, а для собеседников они останутся непрочитанными (одна галочка).

telegram.privacy.is_read_blocked(): boolean

Возвращает текущее состояние блокировки отчетов о прочтении.

telegram.messages

Прямое управление сообщениями через сессионный контроллер клиента.

telegram.messages.send(peer_id: number, text: string)

Отправляет новое текстовое сообщение в указанный диалог по его peer_id.

telegram.messages.edit(peer_id: number, msg_id: number, text: string)

Редактирует ранее отправленное сообщение с идентификатором msg_id.

telegram.messages.delete(peer_id: number, msg_id: number)

Удаляет сообщение из локальной истории и на сервере.

telegram.command & Слэш-команды

Обработка пользовательских команд со слэшем (/command args). Вызывается через глобальный хук on_command(cmd, args).

on_command(cmd: string, args: string): boolean

Перехватывает отправку команды в поле ввода. Если функция возвращает true, отправка сообщения в чат прерывается (команда выполняется локально). Если возвращает false или nil, текст отправляется как обычное сообщение.

telegram.timer

Безопасные таймеры, синхронизированные с главным циклом событий Qt (Main Thread).

telegram.timer.set_timeout(delay_ms: number, callback: function): number

Вызывает функцию callback один раз через указанное количество миллисекунд. Возвращает числовой дескриптор таймера.

telegram.timer.set_interval(interval_ms: number, callback: function): number

Вызывает функцию циклически каждые interval_ms миллисекунд.

telegram.timer.clear_timeout(id: number) / clear_interval(id: number)

Останавливает и удаляет активный таймер по его ID.

telegram.http

Асинхронные сетевые запросы через QNetworkAccessManager. Запросы не блокируют интерфейс клиента.

telegram.http.get(url: string, headers: table, callback: function)

Выполняет GET-запрос. В функцию обратного вызова передаются два параметра: callback(response_body, http_status).

telegram.http.post(url: string, headers: table, body: string, callback: function)

Выполняет POST-запрос с телом body. Обратный вызов имеет аналогичную сигнатуру callback(response_body, http_status).

Пример асинхронного запроса 
telegram.http.get("https://api.github.com/zen", { ["User-Agent"] = "TelegramPlugin" }, function(body, status)
    if status == 200 then
        telegram.ui.show_toast("Мудрость дня: " .. body)
    else
        telegram.ui.show_toast("Ошибка HTTP: " .. tostring(status))
    end
end)

telegram.storage

Изолированное хранилище ключ-значение для каждого плагина. Данные сохраняются в формате JSON в папке плагинов.

telegram.storage.set(key: string, value: any)

Сохраняет значение (строку, число, булево значение или таблицу) под указанным ключом.

telegram.storage.get(key: string): any

Считывает ранее сохраненное значение или возвращает nil, если ключ отсутствует.

telegram.user & telegram.chat

Инспекция активного контекста пользователя и текущего открытого диалога.

telegram.user.get_me(): table

Возвращает таблицу с полями авторизованного аккаунта: id, first_name, last_name, username, phone.

telegram.chat.get_active_chat(): table

Возвращает информацию об открытом чате: id, title, type ("user", "chat", "channel"). Если чат не открыт, возвращает nil.

Пример: Кастомизация темы и QSS

Плагин custom_theme.lua позволяет мгновенно менять внешний вид клиента с помощью стилей Qt или передавать произвольные CSS-свойства командой /css <правила>.

plugins/custom_theme.lua 
PLUGIN = {
    name = "UI & Theme Stylist",
    description = "Инъекция QSS и кастомные стили (/theme cyberpunk, /css ...)",
    version = "1.0.0"
}

local THEMES = {
    cyberpunk = [[
        QMainWindow, QWidget {
            background-color: #0d0221;
            color: #00f0ff;
            font-family: 'Consolas', 'Segoe UI';
        }
        QLineEdit, QTextEdit {
            background-color: #1a0840;
            color: #ff007f;
            border: 1px solid #00f0ff;
            border-radius: 6px;
        }
    ]],
    reset = ""
}

function on_command(cmd, args)
    if cmd == "/theme" or cmd == "theme" then
        local name = args:gsub("^%s*(.-)%s*$", "%1")
        if THEMES[name] ~= nil then
            telegram.ui.set_style_sheet(THEMES[name])
            telegram.ui.show_toast("Тема изменена: " .. name)
            return true
        end
    elseif cmd == "/css" or cmd == "css" then
        telegram.ui.add_style_sheet(args)
        telegram.ui.show_toast("CSS применен")
        return true
    end
    return false
end

Пример: Контекстные меню и нативные диалоги

Плагин context_and_privacy.lua демонстрирует регистрацию действий в меню сообщений и диалогов, интерактивные модальные окна ввода (prompt) и работу с системным буфером обмена.

plugins/context_and_privacy.lua 
PLUGIN = {
    name = "UI Actions & Menus",
    description = "Контекстные меню для сообщений и чатов, диалоги ввода и буфер обмена",
    version = "1.0.0",
    author = "timesplinter"
}

function on_enable()
    -- Добавляем пункт в контекстное меню сообщения
    telegram.ui.add_message_action("Скопировать ID и текст", function(msg)
        local formatted = string.format("[Msg #%s (Peer %s)]: %s", tostring(msg.id), tostring(msg.peer_id), msg.text)
        telegram.clipboard.set(formatted)
        telegram.ui.show_toast("Скопировано в буфер!")
    end)

    -- Быстрый нативный промпт для цитаты
    telegram.ui.add_message_action("Создать цитату...", function(msg)
        telegram.ui.prompt("Цитата сообщения", "Введите комментарий...", "> " .. msg.text, function(comment)
            if comment and #comment > 0 then
                telegram.ui.set_input_text(comment)
            end
        end)
    end)

    -- Действие в контекстном меню списка диалогов (слева)
    telegram.ui.add_chat_action("Инфо о чате", function(chat)
        local info = string.format("Чат: %s\nID: %s\nТип: %s",
            chat.name,
            tostring(chat.id),
            chat.is_channel and "Канал / Супергруппа" or (chat.is_user and "Личный диалог" or "Группа")
        )
        telegram.ui.alert("Параметры чата", info)
    end)

    telegram.ui.show_toast("UI Actions плагин готов!")
end

Пример: Режим невидимки (Ghost Mode)

Управление сетевыми индикаторами конфиденциальности через слэш-команды. Позволяет читать любые чаты без отправки отчетов о прочтении и скрывать статус набора текста.

plugins/ghost_mode.lua 
PLUGIN = {
    name = "Ghost Mode & Privacy",
    description = "Скрытие статуса печати и отметок о прочтении (/ghost, /notyping, /noread)",
    version = "1.0.0"
}

function on_command(cmd, args)
    if cmd == "/ghost" or cmd == "ghost" then
        local current = telegram.privacy.is_ghost_mode()
        local next_state = not current
        telegram.privacy.set_ghost_mode(next_state)
        telegram.ui.show_toast(next_state and "Ghost Mode: ВКЛЮЧЕН (невидимка)" or "Ghost Mode: ВЫКЛЮЧЕН")
        return true
    elseif cmd == "/notyping" or cmd == "notyping" then
        local current = telegram.privacy.is_typing_blocked()
        telegram.privacy.set_typing_blocked(not current)
        telegram.ui.show_toast("Скрытие набора: " .. (not current and "ВКЛ" or "ВЫКЛ"))
        return true
    elseif cmd == "/noread" or cmd == "noread" then
        local current = telegram.privacy.is_read_blocked()
        telegram.privacy.set_read_blocked(not current)
        telegram.ui.show_toast("Скрытие прочтений: " .. (not current and "ВКЛ" or "ВЫКЛ"))
        return true
    end
    return false
end

Пример: Слэш-команды, таймеры и калькулятор

Демонстрация вычисления математических выражений /calc, чтения профиля /whoami и отложенных напоминаний через telegram.timer:

plugins/mega_tools.lua 
PLUGIN = {
    name = "Mega Tools",
    description = "Команды /calc, /whoami, /timer",
    version = "1.0.0"
}

function on_command(cmd, args)
    if cmd == "/calc" or cmd == "calc" then
        local fn, err = load("return " .. args)
        if fn then
            local ok, res = pcall(fn)
            if ok then
                telegram.ui.set_input_text("Результат: " .. tostring(res))
            else
                telegram.ui.show_toast("Ошибка расчета: " .. tostring(res))
            end
        end
        return true
    elseif cmd == "/whoami" or cmd == "whoami" then
        local me = telegram.user.get_me()
        telegram.ui.show_toast(string.format("Я: %s (@%s), ID: %s", me.first_name, me.username or "нет", tostring(me.id)))
        return true
    end
    return false
end

Пример: Модификаторы сообщений и сокращения

Автоматическая замена текстовых сокращений (.shrug, .ping, .lenny) перед отправкой в сеть с помощью хука on_message_send.

plugins/shrug_and_greeter.lua 
PLUGIN = {
    name = "Auto Shrug & Greeter",
    description = "Заменяет сокращения .shrug, .lenny, .ping перед отправкой",
    version = "1.0.0",
    author = "Community"
}

function on_message_send(text)
    if text == ".shrug" then
        return "¯\\_(ツ)_/¯"
    elseif text == ".lenny" then
        return "( ͡° ͜ʖ ͡°)"
    elseif text == ".ping" then
        return "Pong! (отправлено через Lua)"
    end
    return text
end

function on_message_received(peer_id, text)
    if text and text:lower():find("привет") then
        telegram.ui.show_toast("Новое приветствие в чате #" .. tostring(peer_id))
    end
end

Тонкости запуска и безопасность

В клиентах на Qt вызовы виджетов до момента создания главного окна ведут к аварийному завершению. В текущей версии ядра приняты следующие меры:

Отложенная стилизация: если плагин вызывает set_style_sheet внутри on_enable() во время первоначального старта клиента, стиль встает в безопасную очередь и применяется только после того, как SessionController и окно авторизации сформированы. Это исключает падения драйвера ANGLE OpenGL.

Изоляция сбоев и типичные ошибки

Среда выполнения Lua 5.4 изолирована от крашей: синтаксические и рантайм ошибки скриптов оборачиваются через pcall / lua_pcall и логируются в файл log.txt в каталоге клиента.

Главный поток Qt: сетевые колбэки и системные диалоги автоматически синхронизируются с главным потоком приложения через диспетчер crl::on_main, что предотвращает гонки данных и падения при работе с памятью виджетов.
